## Findings considered and rejected or deferred

- **Unlock-cookie expiry / revocation** (`worker/src/auth.ts:78-113`): the design doc (`docs/plans/2026-09-02-share-design.md` §5.3) deliberately chose a 30-day path-scoped HMAC cookie with password-salt rotation as the revocation mechanism. Not a finding against the design; revisit only if per-session revocation becomes a requirement.
- **Go render mutex** (`go/internal/server/markdown.go:194-196`): serializes rendering; steady-state is cached. Not worth a plan.
- **Splitting `server.ts` / `cli.ts` / `App.svelte`**: L effort, real merge-surface cost, but no correctness win; the seams are documented in the audit (Go's file layout). Defer until the P1/P2 fixes land — several of them get simpler after 013 exists.
- **`golang.org/x/net` indirect bump** (`go/go.mod:15`, v0.26.0): do it as a one-line chore with `go get -u golang.org/x/net && go mod tidy` and `govulncheck ./...`; too small for a plan.
- **Dead highlighter methods** (`isPointInHighlight`, `getPositions`, `findClosestOccurrence`): pure deletion; fold into any plan touching `src/lib/highlight/` or do as a chore.
- **Dropping `"node"` from `worker/tsconfig.json` types**: blocked on splitting `comment-storage.ts` into a Node-free format module; a follow-up after 008/011 settle that file.
- **Worker per-request re-resolution of comments** (`worker/src/page.ts`, `comments.ts`): a real CPU cost but small at the stated 5–10 user scale; 005's retry loop re-reads anyway. Revisit with an etag-keyed memo if Worker CPU becomes a bill.
- **Mermaid render concurrency / MarkdownIt instance hoisting**: nice-to-have perf; not planned.
- **`readit remote list` orphan detection**, **hiding "clear all comments" in hosted mode**: small follow-ups noted inside plans 009 and 005.
- **Direction items not planned**: comment status + category schema change (US-007, roadmap v0.5.0), author attribution (US-011), Go server purpose (design doc already scopes Go parity out; document it as local-viewer-only or publish binaries), `readit share --watch` auto-republish (roadmap and design doc disagree — resolve the contradiction before building). Grounded options, maintainer's call.
- **DX-05 root `.env`**: an untracked, gitignored file with deployment credentials exists at the repo root and nothing in the repo reads it (the Worker uses `worker/.dev.vars`; CI uses repository secrets). Not a code change; operator action: delete it or document it, and rotate the tokens it holds if it was ever synced or shared.
